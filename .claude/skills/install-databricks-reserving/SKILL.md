# Install Actuary in Databricks

Read [the installation workflow](../../../skills/install-databricks-reserving/SKILL.md)
and follow it from the repository root. With no arguments, start the guided
demo. Show the catalog before creating the demo schema and wait for
**Set up the demo**. After deployment, show the new schema's empty
**Tables** section. Wait for **Run the import**, then tell the user
when to refresh that page to see the new table.
Then guide the user through running Mack in Databricks and opening its
saved draft there. Carry the same job run ID into Genie and Claude via MCP.
